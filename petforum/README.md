PetForum by Fernando Cantu and Fidel Rodriguez

Project Description

PetForum is a web application designed to connect people who own similar types of pets. Users will be able to choose a pet category, such as dogs, cats, birds, or reptiles, and communicate with other people who own those pets.

The goal of our application is to create a community where pet owners can ask questions, share experiences, give advice, and discuss topics related to their pets.

Our application will be developed using Python and Django, and we will use GitHub to manage our code and collaborate as a team.

Planned Features

User Accounts: Users will be able to register, log in, and manage their accounts.

Pet Categories: Users can browse different categories depending on the type of pet they own.

Discussion Posts: Users can create posts to ask questions or share information.

Comments: Users can respond to posts and interact with other pet owners.
